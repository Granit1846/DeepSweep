# DeepSweep Pro: покупка и активация

Pro — это та же игра, но с открытым **Premium** и без читов. Покупка разовая, без подписки.
Ключ проверяется на устройстве, поэтому для активации интернет не нужен.

## Что даёт Premium

- весь магазин открыт: темы, мины, буи, цифры и рамки профиля;
- опыт ×2 в любом режиме и на любой сложности;
- все заработанные кристаллы ×3;
- все режимы доступны сразу, без прокачки уровня.

## Как купить

1. Оплатите покупку на странице товара — **ссылка появится здесь** (Digiseller/Plati, Boosty или другой канал).
2. После оплаты вы получите код активации вида `DSWP1.…` (на почту или в сообщении).
3. Скачайте Pro-сборку из [GitHub Releases](https://github.com/Granit1846/DeepSweep/releases) и установите поверх обычной — прогресс сохранится.
4. В игре откройте **Магазин → ★ Premium → «У меня есть код»**, вставьте код и нажмите «Активировать».
5. Готово: Premium включён навсегда на этом устройстве. Код остаётся в сохранении, при обновлениях и сбросе прогресса Premium не теряется.

Если код не подошёл, проверьте, что он скопирован целиком (в нём нет пробелов, но переносы строк допустимы).

## Где принимать оплату

GitHub не принимает платежи — он только хранит APK. Деньги нужно принимать на стороне,
и для продажи цифрового товара в РФ нужен хотя бы статус самозанятого (НПД) или ИП.
Это не юридическая консультация: проверьте актуальные условия площадки и налоги.

| Вариант | Плюсы | Минусы |
|---|---|---|
| **Digiseller / Plati.Market** | магазин цифровых ключей: сам принимает оплату, автоматически выдаёт код и файл, выплаты в РФ | комиссия площадки, нужна модерация товара |
| **Boosty** | быстрый старт, оплата картой РФ, можно приложить APK и код | подписочная модель, выдача кодов менее автоматизирована |
| **Самозанятость + ЮKassa/Robokassa** | свой лендинг, полный контроль, чеки | нужно зарегистрировать НПД, настроить приём платежей и выдачу кодов |

Практичный старт: **самозанятость + Digiseller** (ключи выдаются автоматически, код вставляется в приложение).
Партию кодов генерируйте заранее (см. ниже) и загружайте в товар; `issued.csv` храните как реестр продаж.

## Техническая часть

### Сборки

```bash
./gradlew :app:assembleFreeRelease    # RuStore: без Premium и без покупок
./gradlew :app:assembleProRelease     # Pro: Premium по коду активации, без читов
```

APK Pro: `app/build/outputs/apk/pro/release/app-pro-release.apk`.
Обе сборки используют один `applicationId` и одну подпись, поэтому Pro ставится поверх free
без потери прогресса. Читы есть только в `debug`-вариантах.

`versionCode` у Pro сдвинут на 100000 (free `1` → Pro `100001`): обновление free-сборки из RuStore
не сможет «понизить» установленный Pro и молча отобрать Premium. При выпуске новой версии
поднимайте оба числа: `1.1.0` → free `2` / Pro `100002`.

### Как выпустить код

```bash
tools/license/gen-keys.sh              # один раз: создаёт ключевую пару
tools/license/issue-license.sh DS-0001 # печатает код и пишет строку в issued.csv
```

- Приватный ключ лежит в `tools/license/keys/license-private.pem` и в git не попадает.
  Сделайте офлайн-копию (менеджер паролей, флешка) и не теряйте её: без неё новые коды не выпустить.
- Код подписан ECDSA P-256 / SHA-256. Публичная половина вшита в
  `app/src/main/java/com/skeorz/lab/deepsweep/meta/License.kt`, поэтому приложение проверяет код
  офлайн и не требует аккаунта или сети.
- `issued.csv` — реестр: номер заказа, дата, код. Тоже не коммитится, но храните его: по нему
  видно, какие коды проданы.

### Ограничения, о которых стоит знать

- Код нельзя отозвать: проверка офлайн, поэтому «забанить» уже выданный код нельзя.
- Код можно передать другому человеку. Для игры за пару сотен рублей это нормальный компромисс;
  DRM и онлайн-проверки обойдутся дороже, чем потери.
- APK можно пропатчить. R8 немного усложняет задачу, но не защищает от целевого взлома.
- Если ключевая пара будет пересоздана, старые коды перестанут работать — выпускайте обновление
  с новым публичным ключом и поддержкой обоих ключей в переходный период.

## Чек-лист запуска

1. Оформить самозанятость (если продаёте как физлицо) или выбрать площадку.
2. Сгенерировать ключи и сохранить приватный ключ вне репозитория.
3. Собрать `assembleProRelease`, проверить активацию тестовым кодом.
4. Опубликовать Pro APK в GitHub Releases.
5. Создать товар на площадке, загрузить партию кодов.
6. Вставить ссылку на товар в этот файл (кнопка «Купить Premium» ведёт сюда).
7. Проверить полный путь: оплата → код → установка → активация → Premium в игре.
